# Raw results

These are the outputs of the runs reported in the paper. `make_figures.py` reads the JSON files.

| File | Experiment | Contents |
|---|---|---|
| `e18/<env>_<regime>.json` | E18 | learning curves (exact normalised score per checkpoint, 5 seeds), V*, V_random and the exact-planning references |
| `e18/<env>_transfer.json` | E18 transfer | score at the training latent and on 8 held-out latents, per seed |
| `rep/<env>_seed0.json` | E8, E13–E16 | test MSE and parameter count per model, planted-solution check and diagnostics |
| `e10.json` | E10 | depth profile and permutation-averaged deficit |
| `e07.txt`, `e09.txt`, `e12.txt`, `e17.txt`, `e17b.txt` | E7, E9, E12, E17, E17b | printed output of the exact checks |
| `e19/` | E19 | 2×2 study, transfer, planners and horizon runs (`*.json`), `summary.md`, console logs in `e19/logs/` |
| `e20/e20_results.json` | E20 | aggregators, M-operator family, slack spread, leaf values |
| `e21/e21_results.json`, `e21/e21_lower_bound.json` | E21 | miscalibrated operators; M-operator lower bound and cost |
| `e22/e22_results.json` | E22 | learned vs exact score, drift and switching for β ∈ {0.5,…,20} |
| `e23/e23_results.json` | E23 | hidden-latent learning curves, plug-in transfer, blind/oracle references |
| `e24/e24_results.json` | E24 | distance to the exact certificate per checkpoint, two step-size rules |
| `rep_*.txt`, `e18_*log.txt` | — | console logs |
| `table_*.tex`, `e18_reference.txt` | — | tables generated by `make_figures.py` |

`e18_log.txt` was written across one interrupted and resumed run. `e18_control.py` resumes an
interrupted run by keeping agents that have already finished, so the log contains some repeated
headers and incomplete runs. The JSON files are authoritative.
